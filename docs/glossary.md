| Term | Meaning |
| ---- | ------- |
| ECHO | Environmental Cue and Heading Output — auditory presentation for a human driver |
| ViDAR | Allsparks spatial observation project |
| HELM | Allsparks intent / task selection |
| TRACE | Allsparks recording / replay |
| MIMIC | Allsparks mechanism lifecycle |
| AMPER | Allsparks electrical observation |
| BEACON | Allsparks communication health |
| Bearing | Robot-relative angle, 0 forward, +right, radians |
| Presence | UNKNOWN, UNAVAILABLE, STALE, or PRESENT |
| Silence | Valid output meaning “no trustworthy useful cue” |
| Pan | Stereo intensity −1…+1, not HRTF |
| Pulse | Time between cue onsets |
| Driver Hub | REV-31-1596, official DS device |
| Conditional Go | Train/simulate; match audio gated |
| Feature flag | Runtime enable; defaults off for I/O |
