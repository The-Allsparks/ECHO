# ADR 0001: Conditional Go

- Status: Accepted
- Date: 2026-08-17

## Decision

ECHO’s Phase -1 result is **`CONDITIONAL GO`**. Implement deterministic core and desktop training. Keep match audio, Android renderers, and FTC output adapters disabled.

## Why

Primary sources do not jointly prove a legal, reachable, stereo, Driver Hub transducer path. Official DS sound APIs exist but do not complete the architecture. See `docs/feasibility-decision.md`.

## Consequences

README maturity must stay honest. Training UI must not be labeled competition-ready.
