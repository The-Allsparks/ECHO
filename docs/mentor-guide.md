# Mentor guide

ECHO is a student-teachable **display** project. Mentors gate anything that makes sound near a robot or event.

## How to talk about it

> ViDAR determines where things are. ECHO turns selected robot information into sound for the driver.

Add: “Right now that sound is a desktop trainer. It is not legal just because the repo exists.”

## Gates you own

1. No Driver Hub audio experiments without reading `docs/feasibility-decision.md` and the current manual.
2. No Q&A submission without Lead Coach authorization.
3. No claim that driving improved.
4. Feature flags stay off in any robot project that copies this library.
5. Hearing: students set OS volume; you watch for “turn it up” culture.

## Mapping to Allsparks siblings

Keep ownership sentences on the wall. ECHO adapters are optional. If ViDAR is absent, ECHO should be quiet, not clever.

## Classroom sequence

Phase 0 worksheets → Phase 1 headphones in a quiet room → stop. Phases 2+ are software contracts until you explicitly reopen feasibility after Kickoff.
