# Hearing safety

Guidance cited in [research/hearing-and-human-factors.md](research/hearing-and-human-factors.md) (NIOSH 85 dBA 8-h REL; WHO-ITU 80/75 dB weekly personal-audio modes). ECHO is not a hearing-conservation program.

## Software controls

| Control | Default |
| ------- | ------- |
| Linear gain | 0.08 |
| Maximum gain | 0.20 |
| Desktop audio flag | off |
| Envelope | 8 ms fade in/out |
| Mute | immediate; renderer stops writing samples |

## Practice rules for students

1. Start with OS volume low and ECHO gain at default.
2. Never use ECHO to drown venue noise.
3. Stop if ears ring, speech is hard to hear, or referees/coaches cannot be understood.
4. Two-ear isolation is a communication risk even in the shop.

Physical SPL is **not** measured in this repository. Do not treat digital gain as dBA.
