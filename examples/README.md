# Examples

These sketches do not enable match audio and do not command hardware.

| Example | Purpose |
| ------- | ------- |
| [phase0-select-snapshot.md](phase0-select-snapshot.md) | Build a snapshot and print why a cue was chosen |
| [phase1-desktop.md](phase1-desktop.md) | Run the training UI |
| [phase2-vidar-replay.md](phase2-vidar-replay.md) | ViDAR DTO, `vidarAdapter` gate, and `echo-replay.v0` fixtures |
| [phase3-amper-replay.md](phase3-amper-replay.md) | AMPER warning DTO, `amperAdapter` gate, and preemption replay |

OpMode / Driver Station bridges are **not** provided. They would be a later, gated adapter.
